CampusFind Pro - Campus Lost & Found Portal

Run locally:
1. Extract the ZIP.
2. Open the CampusFind_Pro folder.
3. Double-click index.html in a modern browser.

Interactive features:
- Dashboard with live listing statistics and recent reports.
- Separate Dashboard, Browse Items, Report an Item and My Reports views.
- Add a lost/found report with category, location, date, description and optional contact.
- Search by item name, location, category or description.
- Filter by report type and category.
- Open each listing to see a full details modal.
- Mark an item as returned or delete a report.
- Confirmation toast after publishing and status updates.
- Reports persist using browser localStorage.

Limitations:
This is a polished front-end demonstration. It has no login, server or shared database. Data is stored in the browser on the current device, so different students/devices will not share reports. For a real campus-wide service, connect a backend/database and authentication. Do not publish sensitive personal contact details.
